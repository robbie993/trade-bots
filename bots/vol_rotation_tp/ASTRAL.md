# The ten take-profit iterations, as Astral prompts

Paste one block at a time into Astral's strategy builder (heyastral.ai). Each
block is self-contained and describes exactly what the matching file in this
folder does, with every number the code uses, so a backtest there and a
backtest here are tests of the same strategy.

Generated by `python scripts/vol_rotation_astral.py` from the bots' own
parameters. Change a bot, rerun the script, and this file follows. Do not edit
it by hand.

**Check what Astral built before you trust its backtest.** It writes the
strategy from these words, and an AI builder can quietly change a rule, for
example by dropping the volume gate or reading "tranche" loosely. Its editor
shows the rules it wrote, so check them against the block you pasted.

## 01. ATR Target

A fixed target 12 average true ranges above entry. The plainest way to ask for a bigger win: name it, and wait for it.

Repo version: `bots/vol_rotation_tp/tp01_atr_target.py`

```text
Build a volatility rotation strategy called "Treasuries TP: ATR Target".

Universe: TLT, TLH, IEF. Long only, no leverage, no shorting. Timeframe: regular US market hours only (9:30-16:00 ET), 15-minute bars.
Evaluate on each bar close.

Indicators, per ticker:
- Short volatility = standard deviation of 1-bar log returns over the last 32 bars.
- Long volatility = standard deviation of 1-bar log returns over the last 128 bars.
- Vol ratio = short volatility / long volatility.
- Annualised volatility = short volatility x sqrt(6552).
- Momentum = ln(close / close 16 bars ago).
- Score = momentum / (short volatility x sqrt(16)).
- Relative volume (RVOL) = this bar's volume / average volume of the previous 31 bars.
- VWAP = volume-weighted average close over the last 32 bars.
- Up bar = close > open. Down bar = close < open.

Ranking and rotation:
- Eligible = score > 0.5 AND vol ratio <= 2.0.
- Rank eligible tickers by score, adding 0.5 to the score of any ticker currently held (so a challenger must clearly beat a holding to replace it).
- Targets = the single best-ranked ticker.

Position sizing:
- Full position per ticker = 25% of equity x min(1, 12% / annualised volatility).
- A full position is split into 3 equal tranches.

Scaling in (targets only), on a bar where ALL are true: up bar, close > VWAP, RVOL >= 1.1:
- Buy 1 tranche, or 2 tranches if RVOL >= 2.0, never exceeding the full position.
- A quiet up bar (RVOL < 1.1) adds nothing.

Scaling out:
- Exit the whole position immediately if score < 0 or vol ratio > 2.0.
- A held ticker that is no longer a target: sell 1 tranche per bar; 2 tranches if RVOL >= 1.1; everything if RVOL >= 2.0 on a down bar.
- A held target that prints a down bar below VWAP with RVOL >= 1.1 (distribution): sell 1 tranche.
- If a holding is worth more than 110% of its full position (volatility rose), trim it back to the full position.
- If a sale would leave less than a quarter of a tranche, sell the whole position.

Process sells before buys on each bar. Backtest with commissions and slippage on.

Take profit (this overrides the scaling-out rules above):
- ATR = average true range over the last 32 bars.
- Sell the whole position when close >= average entry + 12 x ATR.
- While close > average entry price, ignore every scaling-out rule above (rotation, distribution, negative score, vol spike, trim). Only this take profit closes a winning position.
- When close falls back to or below the average entry price, all the scaling-out rules above apply again.
- A winning position held after it stops being a target still counts toward the number of tickers held, so do not open a new ticker in its place until it is closed.
```

## 03. 4R Structure Target

Risk is set by the chart, not by volatility: 1R is the drop from entry to the swing low the run started from (at least 1.5 ATR). Aim for 4R. A loss is capped at 1R and a win is four of them, so it can be wrong most of the time and still come out ahead.

## 10. Fibonacci Extension

Measure the leg from the 128-bar low up to entry, and target its 2.618 extension. That is 1.618 more legs above entry.

Repo version: `bots/vol_rotation_tp/tp10_fib_extension.py`

```text
Build a volatility rotation strategy called "Treasuries TP: Fibonacci Extension".

Universe: TLT, TLH, IEF. Long only, no leverage, no shorting. Timeframe: regular US market hours only (9:30-16:00 ET), 15-minute bars.
Evaluate on each bar close.

Indicators, per ticker:
- Short volatility = standard deviation of 1-bar log returns over the last 32 bars.
- Long volatility = standard deviation of 1-bar log returns over the last 128 bars.
- Vol ratio = short volatility / long volatility.
- Annualised volatility = short volatility x sqrt(6552).
- Momentum = ln(close / close 16 bars ago).
- Score = momentum / (short volatility x sqrt(16)).
- Relative volume (RVOL) = this bar's volume / average volume of the previous 31 bars.
- VWAP = volume-weighted average close over the last 32 bars.
- Up bar = close > open. Down bar = close < open.

Ranking and rotation:
- Eligible = score > 0.5 AND vol ratio <= 2.0.
- Rank eligible tickers by score, adding 0.5 to the score of any ticker currently held (so a challenger must clearly beat a holding to replace it).
- Targets = the single best-ranked ticker.

Position sizing:
- Full position per ticker = 25% of equity x min(1, 12% / annualised volatility).
- A full position is split into 3 equal tranches.

Scaling in (targets only), on a bar where ALL are true: up bar, close > VWAP, RVOL >= 1.1:
- Buy 1 tranche, or 2 tranches if RVOL >= 2.0, never exceeding the full position.
- A quiet up bar (RVOL < 1.1) adds nothing.

Scaling out:
- Exit the whole position immediately if score < 0 or vol ratio > 2.0.
- A held ticker that is no longer a target: sell 1 tranche per bar; 2 tranches if RVOL >= 1.1; everything if RVOL >= 2.0 on a down bar.
- A held target that prints a down bar below VWAP with RVOL >= 1.1 (distribution): sell 1 tranche.
- If a holding is worth more than 110% of its full position (volatility rose), trim it back to the full position.
- If a sale would leave less than a quarter of a tranche, sell the whole position.

Process sells before buys on each bar. Backtest with commissions and slippage on.

Take profit (this overrides the scaling-out rules above):
- ATR = average true range over the last 32 bars.
- Swing low = lowest low of the last 128 bars. Leg = average entry - swing low (at least 1 ATR). Sell the whole position when close >= swing low + 2.618 x leg.
- While close > average entry price, ignore every scaling-out rule above (rotation, distribution, negative score, vol spike, trim). Only this take profit closes a winning position.
- When close falls back to or below the average entry price, all the scaling-out rules above apply again.
- A winning position held after it stops being a target still counts toward the number of tickers held, so do not open a new ticker in its place until it is closed.
```
